# Pomodoro Focus

A calm, focused Pomodoro timer with:

- Configurable work / short break / long break lengths
- Start, pause, reset, and skip
- Visual SVG progress ring
- Session task list (persisted)
- Session counter with dots
- Optional soft chime on complete
- Auto-start next phase (optional)
- Light & dark mode via system preference
- Settings saved in localStorage

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server 3000
```

## Deploy

Works on GitHub Pages, Cloudflare Pages, Netlify, or any static host.
Just point the root at this folder.
